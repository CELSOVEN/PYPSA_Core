COMO SE REPARTEN LAS RESPONSABILIDADES
--------------------------------------
requirements.txt
    Es el comando sencillo de entrada para instalar el entorno del proyecto.
    Contiene `-e .`, que instala el paquete local en modo editable.

pyproject.toml
    Describe el paquete Python: nombre, version, Python minimo, sistema de
    construccion y dependencias reales. Pip lee este archivo al instalar `-e .`.

DECISION ARQUITECTONICA IMPORTANTE
----------------------------------
SesionNavegacion NO se mueve todavía al Core porque hoy hereda de db.Model y
por tanto está ligado a Flask-SQLAlchemy de cada aplicación.

obligarlos a tener exactamente la misma estructura interna.
